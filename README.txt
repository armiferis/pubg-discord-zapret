PUBG + Discord: zapret без VPN

Windows 10/11 x64.

1. Извлеките ZIP целиком.
2. Запустите Install.bat и подтвердите запрос администратора.
3. Полностью перезапустите PUBG и Discord.

После установки служба запускается вместе с Windows; папку с распакованным архивом можно убрать.
Другой zapret сначала нужно закрыть/удалить, чтобы фильтры не накладывались.
Remove.bat останавливает и удаляет службу; копия файлов остаётся в ProgramData для повторной установки.

Настройки проверены на одном домашнем подключении: вход в матч PUBG и голос Discord работают.
У другого провайдера может потребоваться другая стратегия.

Профиль PUBG: неизвестный UDP 7000–7999, fake ACTIVE_GAME_UDP, TTL 5, repeats 6, cutoff n3.
Остальные правила — из работавшей конфигурации Discord/YouTube.
Адрес сети и имя пользователя не привязаны к конкретному ПК.

Авторы и исходники перечислены в SOURCES.txt.
