# Обход для PUBG и Discord

Готовый комплект zapret для **Windows 10/11 x64 (Intel/AMD)**: вход в матч PUBG и голос Discord без VPN. Работает локально, трафик остаётся у вашего интернет-провайдера.

**[Скачать готовый ZIP](https://github.com/armiferis/pubg-discord-zapret/releases/latest/download/PUBG-Discord-Zapret-Windows.zip)** · [Все релизы](https://github.com/armiferis/pubg-discord-zapret/releases)

1. Извлеките **весь архив** в обычную папку.
2. Запустите `Install.bat` и подтвердите запрос администратора.
3. Полностью перезапустите PUBG и Discord.

Установщик копирует файлы в `%ProgramData%\PUBG-Discord-Zapret` и создаёт службу `zapret-pubg-discord` с автоматическим запуском. После установки распакованную папку можно убрать. `Remove.bat` останавливает и удаляет службу; копия файлов остаётся в ProgramData для повторной установки.

Перед установкой закройте другие батники zapret. Если другой zapret установлен службой, сначала удалите ту установку её штатным способом. Установщик обнаруживает конфликты и не отключает чужие службы автоматически.

Профиль проверен на одном домашнем подключении: **PUBG, Discord и голос Discord работают одновременно**. На другом провайдере или после изменений фильтрации результат может отличаться. ARM64 этим комплектом не поддерживается.

**Что настроено**

- Для неизвестного UDP на портах **7000–7999**: `fake`, шаблон `ACTIVE_GAME_UDP.bin`, `repeats=6`, `TTL=5`, `cutoff=n3`.
- Для Discord и остальных доменов сохранены рабочие правила исходной Windows-конфигурации zapret.
- Подробный журнал пакетов выключен. Служба работает от SYSTEM; менять её файлы могут только SYSTEM и администраторы.

`ACTIVE_GAME_UDP.bin` совпадает с входящим в комплект `quic_initial_4pda_to.bin`, а `ACTIVE_DISCORD_UDP.bin` — с `quic_initial_steamcommunity_com.bin`. Это штатные fake-шаблоны, а не записи личного трафика.

**Авторы и исходники**

Сборка основана на [zapret / bol-van](https://github.com/bol-van/zapret) и Windows-профилях [Flowseal](https://github.com/Flowseal/zapret-discord-youtube). Перехват пакетов выполняет [WinDivert](https://github.com/basil00/WinDivert); также используется [Cygwin](https://cygwin.com/).

Установочные скрипты этого репозитория распространяются по MIT. Лицензии сторонних компонентов находятся в `licenses/`, версии и ссылки на исходники — в [SOURCES.txt](SOURCES.txt). Архивы соответствующих исходников приложены к релизу отдельно. Бинарники сторонних компонентов не изменялись.

Хэши установочных файлов перечислены в `SHA256.json`. Собрать готовый ZIP из этого checkout можно командой `python tools/build_release.py`; результат появится в `dist/`.
