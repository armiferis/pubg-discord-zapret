Обход для PUBG и Discord — v1.0.0

Готовый комплект для Windows 10/11 x64. PUBG, Discord и голос Discord проверены одновременно без VPN на одном домашнем подключении.

Скачайте PUBG-Discord-Zapret-Windows.zip, извлеките целиком и запустите Install.bat. Служба включается в автозапуск. Remove.bat останавливает и удаляет службу.

Профиль PUBG: неизвестный UDP 7000–7999, fake ACTIVE_GAME_UDP, TTL 5, repeats 6, cutoff n3. Для Discord сохранена рабочая конфигурация.

Проверены SHA256 компонентов, целостность ZIP и синтаксис установщика в Windows PowerShell 5.1. Другому провайдеру может понадобиться подстройка параметров.

Архивы с суффиксом source содержат исходники сторонних компонентов; для установки они не нужны. Хэши файлов релиза приведены в SHA256SUMS.txt.
